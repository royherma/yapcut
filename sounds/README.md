# Sounds

`clean/` is made from scratch with ffmpeg by `bin/synth-clean-sounds.mjs` and `bin/synth-scale.mjs`.
`openverse/` is CC0 sounds found through Openverse; who made each one and where it came from is in `SOURCES.csv`.
Add your own: drop WAVs in a folder here and point a pack in `sound-packs.json` at them, or set `YAPCUT_SFX_DIR`.
